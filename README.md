## Quick Summary

Agent ECHO is an accessibility-first  app designed for Deaf and Hard of Hearing users. It helps users stay aware of important sounds, follow conversations through captions, capture tasks from speech, bridge ASL and voice interactions, and contact trusted people during emergencies.

Core features are built using Expo React Native and TypeScript for the mobile app, Node.js and Express for backend APIs, Firebase Firestore for cloud sync, OpenAI APIs for transcription and assistant features, Twilio for emergency SMS alerts, and Google Maps for routing and location support. API keys are hidden and excluded from this GitHub repo for security reasons. Key names are in .env.example for reference. We can not wait to present our app to you at the National Conference!

## Core Features

- Ambient listening for important sounds like alarms, doorbells, knocks, sirens, and name calls
- Live conversation captions with task capture from spoken reminders and plans
- ASL bridge mode for sign-to-speech, speech-to-sign, and service interactions
- Emergency SOS alerts with Trusted Circle contacts and location support
- Medical companion tools for medications, appointment notes, and visit logs
- Firebase-backed cross-device sync for events, actions, contacts, medications, and preferences
